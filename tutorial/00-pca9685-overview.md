# Chapter 0: PCA9685 とは

## 学習目標

- PCA9685 が「何をしてくれるチップなのか」を説明できる
- なぜ Arduino 単体ではなく PCA9685 を使うのか、その理由を言える
- I²C・PWM・パルス幅・周波数 の用語を、サーボ制御の文脈で理解する

## サーボモータは「パルス幅」で動く

RC サーボ（ラジコンサーボ）は、おおよそ **20 ms 周期（= 50 Hz）** の矩形波の
**HIGH の長さ（パルス幅）** で角度が決まります。

```
  ┌──┐                  ┌──┐
  │  │                  │  │
──┘  └──────────────────┘  └────
  ←→
  パルス幅 (約 0.5 ms 〜 2.5 ms)
  ←─────── 20 ms ───────→
```

| パルス幅 | サーボの角度（目安） |
|----------|----------------------|
| 0.5 ms   | -90°（左いっぱい）   |
| 1.5 ms   | 0°（中央）           |
| 2.5 ms   | +90°（右いっぱい）   |

> 実際の対応は機種によって異なります。Ch 1 で **キャリブレーション**（calibration）
> としてこの値を実測します。

## なぜ PCA9685 が必要なのか

Arduino Uno にも `Servo.h` ライブラリはあり、PWM 出力ピンも 6 本あります。
ですが、4 脚ロボット（合計 8〜12 サーボ）になると次の壁にぶつかります。

1. **PWM ピンが足りない**
   Uno のハードウェア PWM は D3, D5, D6, D9, D10, D11 の 6 本だけ。
2. **`Servo.h` がタイマーを占有する**
   `Servo.h` は内部で Timer を使うため、`tone()` や `analogWrite()` と競合します。
3. **CPU 負荷が大きい**
   多数のサーボにソフトウェアでパルスを作り続けると、メインループが圧迫されます。

PCA9685 は、これらをまとめて解決してくれる **「外付け 16ch PWM 専用チップ」** です。
Arduino は I²C で「何 ch を、何の幅で」と命令するだけで、
**残り全部はチップ側がハードウェアで生成**してくれます。

## PCA9685 の基本仕様

| 項目 | 内容 |
|------|------|
| チャンネル数 | 16（1 枚で 16 サーボ） |
| 分解能 | **12-bit**（0〜4095 の 4096 段階） |
| 出力周波数 | 24 Hz 〜 1526 Hz（サーボでは 50 Hz が定番） |
| 通信 | I²C（SDA / SCL の 2 本） |
| I²C アドレス | デフォルト `0x40`、はんだジャンパで変更可 |
| 最大連結数 | 62 枚 → **最大 992 サーボ**まで拡張可能 |
| ロジック電源 | 3.3 V / 5 V どちらも可 |
| サーボ駆動電源 | **別系統で V+ 端子に供給**（最重要） |

## 12-bit PWM の意味

PCA9685 は、1 周期を **4096 ステップ**に分割し、
そのうち何ステップ HIGH にするかを指定して PWM を作ります。

50 Hz（周期 20 ms）で動かす場合、1 ステップは

```
20 ms ÷ 4096 ≒ 4.88 µs
```

たとえば「パルス幅 1.5 ms にしたい」なら、

```
1500 µs ÷ 4.88 µs ≒ 307 ステップ
```

を指定します。これが Ch 1 で出てくる `setPWM(ch, 0, 307)` の中身です。

## I²C ってなに？（軽くおさらい）

I²C（アイ・スクエア・シー）は、**SDA（データ線）と SCL（クロック線）の 2 本**で
複数のデバイスと通信できるシリアルバスです。

- 各デバイスは **アドレス**（PCA9685 は `0x40`）を持つ
- マスタ（Arduino）が「`0x40` さん、これこれの値書き込んで」と話しかける
- 配線が 2 本で済むので、サーボドライバを **複数枚チェーン**できる

```
Arduino                   PCA9685 #1            PCA9685 #2
  SDA ─┬───────────────────── SDA ───────────────── SDA
  SCL ─┼┬──────────────────── SCL ───────────────── SCL
  GND ─┼┼─── GND ──────────── GND ───────────────── GND
       ││
       └┴── プルアップ抵抗（基板に内蔵されています）
```

## PCA9685 ボードの主な端子

```
┌──────────────────────────────────────┐
│  GND  OE  SCL  SDA  VCC  V+          │  ← Arduino側コネクタ
│                                      │
│   [0]  [1]  [2]  ...  [14]  [15]     │  ← サーボ用 3pin × 16ch
│                                      │
│                          V+ ──┐      │
│                          GND─┤├──    │  ← サーボ電源用ターミナル
└──────────────────────────────────────┘
```

| 端子 | 役割 |
|------|------|
| GND  | グラウンド（**Arduino と必ず共通**にする） |
| OE   | Output Enable（LOW で出力 ON、未接続で OK） |
| SCL  | I²C クロック |
| SDA  | I²C データ |
| VCC  | チップのロジック電源（3.3 V or 5 V） |
| V+   | サーボ電源参照（オプション、通常は未接続でOK） |
| 緑のスクリュー端子 | **サーボ駆動用の電源入力**（ここに別電源を入れる） |

## まとめ

- PCA9685 は **Arduino を I²C で動かすだけで 16ch PWM を生成してくれる**外付けチップ
- 4 脚ロボット（8〜12 サーボ）には Uno 単体ではキツいが PCA9685 で解決
- 12-bit 分解能 → 0〜4095 のカウントでパルス幅を指定する
- **ロジック電源とサーボ電源は別系統**にするのが鉄則

次の Chapter 1 では、まず **1 個のサーボを動かして確実に「動いた！」を体感**してから、
複数サーボへ拡張していきます。
